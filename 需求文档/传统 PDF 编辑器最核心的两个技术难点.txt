# 问题1：编辑框是否可以按照标点符号定位？

答案：

**可以，而且这是更合理的方向。**

但是需要明确：

> PDF 本身没有“句子”概念，只有 glyph（字符）和它的位置。

PDF 内部通常是：

```
Text Object

BT
/F1 12 Tf
100 700 Td
(Hello world.) Tj
ET
```

或者：

```
glyph H
x=100
y=700
width=8

glyph e
x=108
y=700
width=6

glyph l
x=114
...
```

PDF.js 提取出来类似：

```javascript
{
 str:"Hello",
 transform:[...],
 width:30,
 height:12
}
```

所以传统编辑器的问题：

它直接把：

```
Hello world.
```

整个 textContent item 生成一个 textarea。

结果：

```
+----------------------+
| Hello world.         |
+----------------------+
```

用户点击任何位置：

整个框选中。

---

## 更好的方式：Segment Engine

应该增加一层：

```
PDF Text Layer

↓

Sentence Segmenter

↓

Editable Segment
```

例如：

原文：

```
The company was founded in 2020. 
It provides cloud services.
The revenue increased rapidly.
```

拆成：

```
Segment 1:
The company was founded in 2020.

Segment 2:
It provides cloud services.

Segment 3:
The revenue increased rapidly.
```

每个 Segment 一个编辑框。

---

## 如何实现？

流程：

### Step 1

pdf.js 获取文字：

```javascript
page.getTextContent()
```

得到：

```json
[
 {
  str:"The",
  x:100,
  y:200
 },
 {
  str:"company",
  x:125,
  y:200
 }
]
```

---

### Step 2

合并 glyph

根据：

* 同一行
* x间距
* y偏差

形成：

```
line:

The company was founded in 2020.
```

---

### Step 3

按照标点切割

规则：

中文：

```
。
！
？
；
```

英文：

```
.
!
?
;
:
```

例如：

```javascript
split(/[。！？.!?;]/)
```

形成：

```javascript
[
{
 text:"The company was founded in 2020.",
 bbox:{
 x:100,
 y:200,
 width:250,
 height:15
 }
}
]
```

---

这样编辑体验：

用户点击：

```
The company was founded in 2020.
```

只出现：

```
+------------------------------+
| The company was founded in 2020 |
+------------------------------+
```

而不是：

```
整个页面文本框
```

# 问题2：编辑框文字如何保持原文字体大小？

这个更难。

也是传统编辑器最大的坑。

原因：

PDF：

不是：

```
text="hello"
font="Arial"
size=12
```

这么简单。

实际：

```
glyph
 |
 font object
 |
 encoding
 |
 transform matrix
 |
 rendering mode
```

很多产品：

读取：

```
fontSize
```

然后：

HTML textarea:

```css
font-size:12px
font-family:Arial
```

结果：

用户看到：

原文：

```
Hello
```

编辑：

```
Hello
```

但是：

字体：

不同

高度：

不同

间距：

不同

所以产生：

```

```

明显不一致。

# 正确方案：Font Fidelity Engine

需要保存：

每个 segment：

```json
{
 text:"Hello",

 font:{
   family:"Helvetica",
   size:12,
   weight:"normal"
 },

 transform:[
   1,
   0,
   0,
   1,
   100,
   700
 ],

 color:"#000000",

 bbox:{
   width:60,
   height:14
 }
}
```

---

编辑时：

不是简单 textarea。

而是：

```
Editable Overlay

+
Original Style Metadata
```

---

## 字体大小计算

不能直接：

PDF pt = CSS px

需要：

```
CSS px = PDF pt × zoom × 96 / 72
```

例如：

PDF:

12pt

浏览器：

16px

---

## 字体不存在怎么办？

这是最大的问题。

PDF里面：

```
ABCDEF+ArialMT
```

可能是：

subset font

你电脑没有。

所以需要：

### 方案1

提取字体：

```
PDF
 |
font stream
 |
browser font-face
```

类似：

```css
@font-face{
src:url(font.ttf)
}
```

---

### 方案2（多数产品）

字体映射：

```
PDF Font

↓

Closest Font

↓

Arial
Helvetica
Times
```

效果：

80-90%。
