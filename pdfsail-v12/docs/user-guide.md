## 1. 快速开始

### 打开编辑器

浏览器访问 `http://localhost:5173`。

### 上传 PDF

1. 点击左上角蓝色 **Upload PDF** 按钮
2. 选择本地的 PDF 文件
3. 等待 PDF 加载完成（页面渲染在画布上）

### 基本工作流程

```
上传 PDF → 编辑内容 → 导出下载
```

## 3. 添加和编辑文本

### 添加新文本

1. 在字体子工具栏设置**字体**、**字号**、**颜色**
2. 点击主工具栏的 **T Text** 按钮
3. 页面右上角出现新的文本块

### 编辑已有文本

**方式一：选中后修改格式**
1. **单击**文本块 → 选中（显示紫色边框）
2. 工具栏自动同步该块的字体/字号/颜色
3. 修改工具栏的值 → 文本块即时更新

**方式二：双击进入编辑**
1. **双击**文本块 → 弹出蓝色边框的 textarea
2. 编辑文字内容
3. 按 `Enter` 确认 或 `Escape` 取消 → 文本块更新

### 拖拽移动

鼠标指针为 🖐 手形 → **按住拖拽**到目标位置

### 缩放

选中文本块后，右下角出现紫色方块手柄 → **拖拽手柄**调整大小

### 删除

双击非文本类型的 block 直接删除。

## 4. 插入图片

1. 点击主工具栏 **🖼 Image** 按钮
2. 弹出系统文件选择器 → 选择一张图片
3. 图片以 160×160 大小添加到页面
4. **拖拽**移动位置
5. **选中后拖拽右下角手柄**缩放

## 5. 高亮标注

### 操作步骤

1. 点击主工具栏 **🟡 Highlight** 按钮（按钮变黄）
2. 出现高亮工具栏：
   - **Type**：Text（半透明背景）/ Freehand / Underline（下划线）/ Strike（删除线）/ Wavy（波浪线）
   - **Color**：黄 / 红 / 绿 / 蓝 / 紫
   - **Opacity**：10%–100% 滑块
3. 在 PDF 页面上**按住鼠标拖拽**画框
4. 松开鼠标 → 创建高亮块

### 调整

- 拖拽移动
- 选中后缩放
- 再次点击 🟡 Highlight 退出高亮模式

## 6. 永久涂黑脱敏（Redact）

用于隐藏敏感信息，导出后无法恢复。

### 操作步骤

1. 点击主工具栏 **⬛ Redact** 按钮（按钮变黑）
2. 在页面上**按住鼠标拖拽**框选要遮盖的区域
3. 松开鼠标 → 创建纯黑色矩形
4. 导出 PDF 后黑色矩形会覆盖原文，永久不可见

### 调整

- 拖拽移动位置
- 选中后缩放大小
- 再次点击 ⬛ Redact 退出模式

## 7. 签名

### 打开签名面板

点击 **✍ Signature** 按钮 → 弹出签名窗口

### 三种签名方式

#### 手写签名（Handwriting）

1. 默认进入手写模式
2. 在画板区域**按住鼠标绘制**签名
3. 点击 **Clear** 清除重画
4. 点击 **Use Signature** 添加到页面

#### 图片签名（Photo）

1. 切换到 **Photo** 标签
2. 点击 **Choose Photo** 选择签名图片
3. 图片预览显示在下方
4. 点击 **Use Signature** 添加到页面

#### 艺术签名（Artistic）

1. 切换到 **Artistic** 标签
2. 输入**全名**
3. 选择**颜色**（16 种预设色）
4. 选择**花体样式**（Signature 1–4，四种手写花体字体）
5. 实时预览签名效果
6. 点击 **Use Signature** 添加到页面

## 8. 添加批注

1. 点击主工具栏 **💬 Comment** 按钮
2. 页面右上角出现批注块，默认文字为 "Comment"

## 9. OCR 文字识别

### 全页识别（OCR Page）

1. 点击 **🔍 OCR Page** 按钮
2. 系统分析整页图片
3. 自动过滤已有 PDF 文本区域（只识别图片中的文字）
4. 识别结果作为文本块添加到页面

### 区域识别（OCR Region）

1. 点击 **🎯 OCR Region** 按钮（变紫）
2. 在页面上**按住鼠标拖拽**框选要识别的区域
3. 松开鼠标 → 只对该区域运行 OCR
4. 识别结果作为文本块添加到区域位置

### 注意

- 首次 OCR 需要下载语言包（约 10MB），会稍慢
- 如果识别结果不满意，点击 **Clear All** 清空后重试

## 10. 页面管理

页面控制栏在字体工具栏下方：

| 按钮 | 功能 | 禁用条件 |
|---|---|---|
| **+** | 在当前页后插入空白页 | 无 |
| **−** | 删除当前页 | 只剩 1 页时 |
| **N page(s)** | 当前总页数 | - |
| **↑** | 当前页上移一页 | 第 1 页时 |
| **↓** | 当前页下移一页 | 最后 1 页时 |

移动页面后，编辑的 Block 会自动跟随到对应页面。

## 11. 导出 PDF

### 操作

1. 完成所有编辑
2. 点击 **📥 Export PDF** 按钮
3. 浏览器自动下载 `edited-{原文件名}.pdf`

### 导出原理

1. 加载原始 PDF 文档
2. 在每页对应位置画白色遮罩（覆盖原文）
3. 在遮罩上绘制编辑内容（文本/图片/签名/高亮/脱敏）
4. 输出为新的 PDF 文件

### 注意

- 导出后编辑内容不可修改（如需修改请重新编辑）
- Redact 块导出后永久覆盖原文，不可恢复

|---|---|---|
| 撤销 | `Ctrl+Z` | 回退上一次操作 |

- **↩ Undo**：撤销
- **↪ Redo**：重做

## 常见问题

### Q: 文本框抖动怎么办？

当前架构使用 Figma 级 3 层隔离，编辑框通过 Portal 脱离父级 transform。如果仍有抖动，请检查浏览器缩放比例是否为 100%。

### Q: OCR 识别不准？

- 优先使用 **OCR Region** 框选特定区域
- 确保框选区域包含完整文字
- 中文字体识别受限于 Tesseract.js，复杂排版可能效果不佳

### Q: 导出的 PDF 字体不对？

导出时使用 Helvetica 标准字体画文本，与原 PDF 的嵌入字体不同。已通过白色遮罩解决重影问题。如果需要完全匹配字体，建议在原始 PDF 中编辑后另存。

### Q: 可以编辑原始 PDF 的文字吗？

PDF 编辑是**覆盖式**的——在原文上方叠放新的文本块。原文不会被修改。要修改原文，可以在原文位置添加新的文本块（蓝色边框），导出时用白色遮罩盖住原文。
